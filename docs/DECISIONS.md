# Решения по допущениям (раздел 16 ТЗ)

Файл пополняется по ходу этапов; формат: что выбрано, почему, альтернатива.

## D1. Направление «Маскировки»
**Выбрано:** основной режим `ru_to_lat` — при печати кириллица подменяется латинскими
двойниками; обратный `lat_to_ru` — переключателем в настройках.
**Почему:** пример в ТЗ и формулировка «текст выглядит так же» согласуются с этим
режимом; для скрытия русского ввода нужен именно он.
**Альтернатива:** основной `lat_to_ru`. Отклонена — совпадает хуже с идеей функции.

## D2. Набор пар двойников
**Выбрано:** пары из ТЗ (о, а/А, р/Р, К, у, е/Е, с/С, х/Х, Н, В) + добавленные М, Т, У;
строчные к, в, н, м, т не заменяются (визуально отличимы).
**Альтернатива:** полный список возможных двойников — даёт ложное сходство вместо мимикрии.

## D3. Иконка Anonymous
**Выбрано:** пока не определено; проверка лицензии вынесена в M4. Запасной вариант —
собственная монохромная маска (уже подготовлена: `src-tauri/icons/tray.png`).
**Альтернатива:** SVG из ru.wikipedia с записью автора и лицензии в THIRD_PARTY_NOTICES.md.

## D4. Pause/Break
**Выбрано:** трактуем как F15 (keycode `0x71`); клавиша переназначаема в настройках.
Основные пути отката (DoubleShift, ⌫, ⌥) работают и без неё.

## D5. Shift-тап и DoubleShift
**Выбрано:** первый тап Shift переключает раскладку сразу; если в 400 мс пришёл второй —
откат последней автоконвертации и возврат прежней раскладки; если откатывать нечего —
второй тап возвращает прежнюю раскладку без отката. ТЗ прямо задаёт этот протокол.

## D6. «Правила»
**Выбрано:** подписанный пакет данных (Ed25519), сборка раз в неделю в GitHub Actions,
публикация в GitHub Releases; владелец репозитория — константа `<GITHUB_OWNER>`,
заменяемая одной правкой.

## D7. Ёфикатор
**Выбрано:** выключен по умолчанию, заменяет только однозначные пары («все»/«всё» не трогает).

## D8. Состояние «Маскировки»
**Выбрано:** не сохраняется между запусками, пока не включена опция «Запоминать».

## D9. Минимальная macOS
13.0 задана в `tauri.conf.json` (`minimumSystemVersion`) и во всех docs.

## D10. Цифры в токене
Цифры входят в токен; жёсткие границы — пробел, Enter, Tab и знаки препинания ё/тильда
и т.п. (уточнение к разделу 3.2 ТЗ закреплено прототипом токенизатора в M1).

## D11. Проверка пароля раньше опции «цифры и символы»
Проверка пароля (EN-длина > 6, смешанный регистр + цифры/знаки) выполняется до
предфильтра «цифры и символы» и имеет приоритет.

## D12. Две русские раскладки
Таблицы строятся отдельно для «Russian» (RU) и «Russian – PC» (RussianWin) и сверяются
с `UCKeyTranslate` (M2-тест на реальной системе), не по памяти.
**Практика:** таблицы M1 сгенерированы локальным дампером через `UCKeyTranslate`
прямо из системных источников (`kTISPropertyUnicodeKeyLayoutData`) — сверка
фактически выполнена, M2 повторит проверку CI-тестом при доступности macOS.

## D13. Встроенные словари
**Выбрано:** для M1 — частотные списки OpenSubtitles2018 (hermitdave/FrequencyWords,
CC BY-SA 4.0 на данные), фильтр по алфавиту языка, топ-30 000, плюс минимальные
кураторские дополнения для приёмочных примеров (исполнили, сонату, баха, руб и т.п.).
**Почему:** дистанция от копирования чужих словарей продуктов; полный пакет
словоформ (Hunspell ru/en, OpenCorpora) приходит с подписанным пакетом «Правил» в M6.
**Альтернатива:** коммитить полные Hunspell-словари — большой объём и требование
раз-сворачивания аффиксов, отложено в M6.

## D14. Пароль: критерий
Исходная формулировка ТЗ «строчные + заглавные И цифры/знаки» читается как конъюнкция
всех трех признаков (см. engine::is_password). Пример ТЗ `Qwerty123!` покрывается.
