## M5 Интерфейс — код готов (локальная проверка)

- **Звук** (`platform/macos/sound.rs`, NSSound): встроенные CC0-файлы
  `resources/sounds/{switch,fix}.wav`, свой файл и громкость; звук при
  переключении (`Action::Sound(SoundKind::Switch)`) и при исправлении
  (`SoundKind::Fix`). FR-SND-1.
- **Пауза и счётчик (FR-SYS-3):** меню «Приостановить» (30 мин / 1 час /
  до перезапуска), пункт «Продолжить» показывает оставшееся время; иконка
  ⏸ в заголовке трея. Поток workers обновляет текст счётчика
  «Исправлено: сегодня / всего» раз в 30 с. Счётчик при откате
  исправления (после `stats_add_fixed` и `stats_sub_fixed` — суммарно
  уменьшается на один).
- **Пауза автоматически снимает автоматику** в `handle_key_down`.
- **Автозапуск (FR-SYS-5, SMAppService):** `autostart_status`,
  `autostart_set` (mainAppService register/unregister), конфиг —
  `autostart`; статус в UI.
- **Профили приложений (FR-EXC-3):** режимы Off/ManualOnly/Auto по
  bundle id (поддержка `com.jetbrains.*`); потоки workers: 2 Гц опрос
  frontmost-приложения, смена приложения — применение профиля
  (engine конфиг перекрытия, тап режим Off/ManualOnly); 5 с
  поллинг Games-папки и категории-игры. Папка Games открывается
  командой из UI.
- **Слова-исключения (FR-EXC-1):** вкладка «Словарь» — поиск, добавление,
  удаление, «Вернуть стандартный список» (`exceptions_set_cmd`);
  самообучение (после двух откатов слово временно игнорируется) — M5 UI
  показывает только список, счётчики откатов в памяти.
- **i18n (FR-SYS-6):** встроенные ru/en JSON, выбор языка (system/ru/en)
  на лету; заголовки вкладок обновляются.
- **UI:** вкладки «Основные» (enabled, язык, автопереключение, звуки,
  умная отмена, цифры-символы, Enter-исправление, Games-флаги,
  автозапуск, счётчик, «Открыть журнал», кнопка «Проверить разрешения»),
  «Исправления» (дополнены «о»/«ё» + масками), «Словарь», «Приложения»,
  «Правила» (инфо), «Горячие клавиши» (справка), «О программе».
- Статус smoke-проверки: приложение собирается, запускается, тап
  создаётся, маскировка выключена по умолчанию; 41+18+2+2 теста ок,
  clippy -D warnings, fmt, `npm run build` зелёные.

- Команды UI: `permissions_status`, `open_permissions_pane`, `convert_current_word`,
  `set_enabled_cmd`; вкладка «Разрешения» в настройках с кнопками открытия панелей
  (Accessibility / Input Monitoring).
- Core-мелочи: `flip_text`/`flip_auto` (снапшот-конверт текста), 
  `Engine::evaluate_current_word`, `buffer_is_empty`, тесты дисциплины таблиц

  тап стартует, без разрешений ожидаемо `CGEventTapCreate вернул NULL` —

  неоднозначные клавиши и краевые варианты (EdgeVariant).
- Словари: `fst::Set` + встроенные EN/RU списки по 30 тыс. частотных слов
  (hermitdave/FrequencyWords, CC BY-SA 4.0 — THIRD_PARTY_NOTICES.md) +
  приёмочные дополнения; подключение внешнего орфографа (NSSpellChecker — M3).
- n-gram модель: символьные 3-граммы, веса и «невозможные» сочетания;
  эврика: score(alt) − score(cur) ≥ τ с порогом по длине.
- Движок: автомат с предфильтрами (длина → исключения → технический токен),
  **пароль проверяется приоритетно** (D11), решения с 7 уровнями раздела 3.2,
  маскировка применяяется только на выводе; интерфейс Decision с оценками
  (песочница `--replay`).
- Undo-лог: записи конвертаций, откат последней (окно по времени, буфер пуст).
- CLI: `cargo run -p caramba-core --example replay -- [-l en|ru] 'текст'`.
- Тесты: 32 (юнит + приёмочные таблицы ghbdtn/ckj;yj/руддщ/пароль/исключения,
  маскировка, undo, n-gram) + proptest round-trip таблиц; бенчмарки criterion
  (анализ слова ~1.4–2.1 µs, старт движка ~30 мс).

Не перенесено в M1: `руддщ → hello` — работает по словарю; проверка орфографии
