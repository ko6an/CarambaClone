# QA-чеклист ручной проверки (раздел 13 ТЗ)

Перед отметкой пункта — соберите свежий бинарь (`cargo build -p caramba-app`,
`npm run build`) и запустите `target/debug/caramba-app`.

## Приложения (проверить конвертацию `ghbdtn␣` → `привет␣`)

- [ ] Notes
- [ ] Safari (поле формы)
- [ ] Telegram
- [ ] Mail
- [ ] Chrome
- [ ] VS Code — движок молчит (исключение)
- [ ] Terminal — движок молчит (исключение)

## Безопасность

- [ ] Поле пароля (Safari/Notes Secure Input) — движок молчит, иконка 🔒
- [ ] `ssh`/`sudo password:` prompts (Terminal) — молчит

## Разрешения

- [ ] Первый запуск: мастер показывает статус (✓/✗), кнопки открывают Системные настройки
- [ ] После выдачи прав тап стартует без перезапуска
- [ ] Отзыв разрешения: иконка ⚠️/клавиатура, движок пассивен

## Сон и пробуждение

- [ ] Mac усыплён 30 с: после пробуждения конвертация работает (watchdog включил тап)
- [ ] Ручная смена раскладки: буфер сбрасывается, флаг в меню обновился

## Ручные хоткеи

- [ ] Shift-tap (быстрое нажатие) — смена EN ⇄ RU
- [ ] DoubleShift — откат последней конвертации + возврат раскладки
- [ ] ⌥-тап — откат конвертации / конвертация слова по контексту
- [ ] ⌥⇧R — конвертация выделенного текста (буфер восстановлен)
- [ ] F15 (⇥ Playback, если есть клавиатура с Pause/Break) — откат
- [ ] ⌫ через 2 с после конвертации — Smart Undo, слово во временном игноре

## «Фокусы» и опечатки (Notes)

- [ ] `привет1␣` → `привет!␣`
- [ ] `исполнили сонатуБаха␣` → `исполнили сонату Баха␣`
- [ ] `9хорошо␣` → `(хорошо␣`; `(хорошо0␣` → `(хорошо)␣`
- [ ] `пирогб␣`/`рубю␣` → `пирог,␣`/`руб.␣`
- [ ] `хочуЁ␣` → `хочу!␣`
- [ ] `почемуто␣`,`чтото␣`,`кембы␣`,`хорошобы␣` → `почему-то␣`,`что-то␣`,`кем бы␣`,`хорошо бы␣`
- [ ] `тесет␣` → `тест␣` (курируемая таблица из пакета «Правил»)
- [ ] `ДВе␣` → `Две␣`
- [ ] `еще␣` с ёфикатором → `ещё␣`; `все␣` — без изменений

## Маскировка

- [ ] ⌃⌥M: в RU печатается «мЛкО» — визуально неотличимо, латинские U+006F внутри
- [ ] Индикатор-силэт рядом с флагом; в EN — без подмены
- [ ] Cmd/Ctrl-сочетания не затрагиваются; Caps Lock без подмены
- [ ] Отключение ⌃⌥M — текст обычный RU

## Меню и настройки

- [ ] Флаг 🇺🇸/🇷🇺 в строке меню обновляется при любой смене (< 50 мс)
- [ ] «Включить приложение» — иконка меняется на клавиатуру, движок пассивен
- [ ] «Сменить раскладку» — работает
- [ ] Пауза: 30 мин/1 час/до перезапуска; ⏸ в заголовке; «Продолжить» показывает время
- [ ] Счётчик «Исправлено: N / N» растёт при конвертациях и уменьшается после отката
- [ ] Звук: переключение и исправление (встроенный, громкость, свой файл)
- [ ] Автозапуск: статус enabled в UI; «Системные настройки» показывает приложение
- [ ] i18n: смена языка в UI обновляет вкладки на лету; меню — при следующем старте
- [ ] «Открыть журнал» — открывает `~/Library/Logs/CarambaClone/debug.log`
- [ ] Закрытие окна настроек: приложение продолжает работать (Accessory, нет Dock)
- [ ] Повторный запуск: вторая копия не создаётся (single instance)
