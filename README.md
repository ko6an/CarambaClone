# CarambaClone

Резидентное приложение для строки меню macOS: умный автоматический переключатель
раскладки для тех, кто работает с текстами на русском и английском. Замечает слово,
набранное не в той раскладке, исправляет его на лету и заодно чинит типичные опечатки.
По поведению ориентир — Punto Switcher, Caramba Switcher и YouType.

## Что это и чем полезно

- Автокоррекция EN ⇄ RU в любых приложениях: набрали `ghbdtn` — стало `привет`.
- Эвристика + словари: явные ошибки ловятся мгновенно, остальное — проверкой орфографии.
- Отмена всего одной кнопкой: ⌫, ⌥, двойной Shift.
- «Маскировка» — фирменный режим: часть печатаемых кириллических букв подменяется
  визуально неотличимыми латинскими двойниками.
- Всё локально: текст набранного нигде не хранится и не уходит в сеть.

## Установка

1. Скачайте `.dmg` из Releases и перетащите CarambaClone в «Программы».
2. Аккаунта Apple Developer нет и не планируется, поэтому приложение не нотаризовано.
   Снимите карантин командой:

   ```sh
   xattr -dr com.apple.quarantine /Applications/CarambaClone.app
   ```

   (альтернатива: Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»).
3. Запустите приложение и пройдите мастер разрешений: «Универсальный доступ»
   и «Мониторинг ввода».
4. Если после обновления разрешения «потерялись» (переключатель включён,
   а приложение не реагирует) — удалите запись кнопкой «−» и добавьте приложение заново.

## Использование

Иконка (флаг раскладки) в строке меню открывает меню:

| Пункт | Что делает |
| --- | --- |
| Включить приложение | Глобальный on/off движка |
| Сменить раскладку на … | Ручное переключение EN ⇄ RU |
| Маскировка | Включает и выключает фирменный режим |
| Приостановить | Пауза на 30 мин / 1 час / до перезапуска |
| Исправлено сегодня / всего | Счётчик полезных автокоррекций |
| Настройки… | Окно настроек |

Горячие клавиши (переназначаемы):

- Одиночный Shift — смена раскладки (настройка).
- Двойной Shift — отмена последней автоконвертации.
- ⌫ в течение 2 с после автокоррекции — «умная отмена».
- ⌥⇧R — конвертация выделенного текста.
- ⌃⌥M — вкл/выкл «Маскировки».

## Настройки

Вкладки: Основные, Исправления, Словарь (слова-исключения), Приложения
(исключения по программе, папка Games для игр), Правила, Горячие клавиши, О программе.

## «Замены текста» macOS

Частные конфликты правил проще всего решить системной опцией
(Системные настройки → Клавиатура → Замена текста) — она приоритетнее CarambaClone.
Примеры:

- `--` → `—`
- `of` → `ща` (русское «ща» в английской раскладке)
- `&` → `?` и `^` → `:`
- `ии` → `ИИ`; `здр` → `Здравствуйте!`
- `Улётов` → `Улетов` (если ёфикатор «исправил» фамилию)

## Частые проблемы

- Приложение не ловит нажатия после обновления: см. установку, п. 4.
- Системная автокоррекция macOS мешает: отключите «Исправлять орфографию
  автоматически» (Системные настройки → Клавиатура → Ввод текста → Изменить).
- Terminal и некоторые редакторы в списке исключений — автоматика там выключена.

## Сборка из исходников

Нужны: Rust (stable), Node.js, macOS 13+ на Apple Silicon.

```sh
npm ci
cargo build -p caramba-core
cargo run -p caramba-app
# выпуск .app/.dmg:
npm run tauri build
```

## Конфиденциальность

Набранный текст не пишется на диск и не уходит в сеть. Единственный сетевой
запрос — загрузка пакета «Правил» с GitHub; его можно отключить.
